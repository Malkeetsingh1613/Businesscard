# Personal Portfolio Card

A simple and responsive personal portfolio card built using **HTML and CSS**. This project presents basic personal information in a clean card-style layout.

## 📌 About the Project

This project is a basic personal profile/portfolio card that displays:

* Profile image
* Name
* Professional role
* Location

The card is created using HTML for the structure and CSS for the styling and layout.

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure and content of the profile card.
* **CSS3** – Used for layout, colors, typography, spacing, borders, and overall appearance.

## 📂 Project Structure

Personal-Portfolio/

## ✨ Features

* Clean card-based design
* Profile image section
* Personal information section
* Flexbox-based layout
* Centered card design
* Custom background and text colors
* Rounded corners
* Italic styling for profile information
* Simple and lightweight implementation

## 🎨 Styling

The profile card uses CSS Flexbox to arrange the image and personal information side by side. It also includes custom padding, background color, typography, centered positioning, rounded corners, and a bottom border.

## 🚀 How to Run

1. Clone or download this repository.
2. Make sure `My_portfolio.html`, `styles.css`, and `MSK.jpg` are in the same project folder.
3. Open `My_portfolio.html` in any modern web browser.
